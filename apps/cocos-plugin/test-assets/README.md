# Local test input

Eight original, deterministic 256 × 256 RGBA PNGs, generated by `pnpm fixtures`. No AI or externally licensed artwork is used. The blue knight faces right, with shifting legs and a visible gold frame marker. This is diagnostic artwork rather than a polished walk cycle.

`manifest.json` is authoritative: eight paths under `frames/`, walk, right, 12 FPS, looping, and pivot `(0.5, 0)`. The generation UUID remains a valid manifest identifier; only Test Import overrides the destination folder to `test_walk`.

The fixture generator uses PNG's standard zlib/CRC format and leaves the background transparent. All eight PNG files are included in source and the standalone extension. Re-running the script is deterministic. Never infer ordering by enumerating this directory.
